# ADR-0004 — Proyecto no comercial y atribuciones

- Estado: aceptada · Fecha: 2026-10-10

## Contexto
Open-Meteo, OSRM demo, OpenRouteService, GraphHopper y RainViewer limitan sus planes gratuitos a uso no comercial. El proyecto es personal/portfolio.

## Decisión
- El proyecto **no se monetiza** (sin anuncios, suscripciones ni muros de pago). Se publica con licencia MIT.
- Atribuciones siempre visibles (pie y página "Fuentes de datos").
- Si algún día se monetizara: plan comercial de Open-Meteo y motor de rutas propio (OSRM/Valhalla) **antes** de lanzar, y nueva ADR.

## Consecuencias
+ Coste 0 € y cumplimiento de términos.
− Techo de escalabilidad dado por demos públicos; mitigado por ADR-0002/0003 y el plan B de infraestructura.
